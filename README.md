# Evidence-Based Evaluation Operationalization Recommender

[Open the recommender](https://jhbutter.github.io/Evidence-Based-Evaluation-Operationalization-Recommender/)

The original static interface packaged on 2026-11-17. Open index.html to explore evaluation dimensions, subjective indicators and tools using the bundled 2026-11-13 review dataset.

The interface uses a palette inspired by AI4Design Survey (https://idvxlab.com/ai4design/), applied to the original layout.

The refined interface uses numbered pathway navigation, responsive form panels and expanded evidence rows. Layout styles are in interface.css. Desktop and 390px mobile recommendation flows have been checked.
