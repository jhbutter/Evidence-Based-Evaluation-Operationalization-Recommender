# Evidence-Based Evaluation Operationalization Recommender

[Open the recommender](https://jhbutter.github.io/Evidence-Based-Evaluation-Operationalization-Recommender/)

The static interface packaged on 2026-11-17, with colours inspired by AI4Design Survey (https://idvxlab.com/ai4design/). The original layout, dropdown inputs and result lists are retained. The bundled review dataset is dated 2026-11-13.

Open index.html locally or serve the repository root with GitHub Pages.

Expanded paper evidence uses cards with a stage-coloured header, paper year/title, reported measure and source page.

Current stage colours are green (#66C3A6), cyan-blue (#45C4DB) and periwinkle (#8E9FCB), sampled from the provided reference. The selected background uses #DAF4F8.

Current palette restored to the original 2026-11-17 site: cyan accents, with green (#69BCA6), blue (#8D9FCB) and pink (#DC94B6) for the three stages and their evidence cards.

Low-contrast CSS contour textures decorate the header and background corners. They scale down on mobile and are hidden when printing.

The background now uses an original pale cyan interwoven wave pattern in background-waves.svg, repeated behind the content.

The simplified background uses twelve non-crossing lines, fading toward the reading area and placed once at the right edge.

Current background is a soft blue/green/yellow/pink gradient fading into cool grey-white. The previous wave asset is no longer referenced. Page content and eleven key layout regions were verified unchanged.

Sidebar and recommender panel backgrounds are transparent so the page gradient continues through both regions without rectangular white overlays.

Desktop navigation labels use 18px text; the language label uses 14px.
